# Python Calculator
This is a simple calculator program written in Python.  
It uses a `while True` loop to continuously perform operations until the user chooses to exit.
## Features
- Addition
- Subtraction
- Multiplication
- Division (with division by zero check)
## How to Run
1. Save the file as `calculator.py`.
2. Open Command Prompt and run:
   python Calculator.py
3. Follow the prompts to perform calculations.
